# 🩺 Smart Kidney Disease Detection System

An intelligent machine learning-based system for early detection of kidney disease using patient medical data. This project helps in predicting Chronic Kidney Disease (CKD) and supports faster diagnosis.

## 🚀 Features
- Predicts kidney disease using ML models
- User-friendly interface for input data
- Fast and accurate predictions
- Data preprocessing and analysis included

## 🛠️ Tech Stack
- Python
- Machine Learning (Scikit-learn / Pandas / NumPy)
- Flask / Streamlit (for web app)
- Matplotlib / Seaborn (for visualization)
